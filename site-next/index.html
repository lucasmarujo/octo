    01What is an ADE?

    An Agentic Development Environment. Where an IDE is built around you editing files, an ADE is built around agents doing the work: you launch them, see their status, answer their questions and merge what they made.

    02Is Octo free?

    Yes. Octo is free and open source under the MIT license. The agents run on the subscriptions or API keys you already have, so their providers' charges still apply.

    03Do I have to stop using my editor?

    No. Octo doesn't replace your editor; it replaces the pile of terminals where your agents live. Every agent works in a normal folder or git worktree that any editor can open.

    04What does the orchestrator do, exactly?

    It is a chat that sees all your agents. In Observe it only reports. In Moderate it answers what your rules and the task settle and leaves the rest to you. In Bypass it decides everything. It is off until you turn it on.

    05Where does my code go?

    Nowhere new. Agents run on your machine and talk to their own providers, as they do in a terminal. Octo has no account and no server that sees your code, and never changes your agents' config files.

    06Which agents are supported?

    Claude Code, Codex, Cursor CLI, OpenCode, Kilo, Antigravity, Grok Build, Qwen Code, Kimi Code and Pi, plus plain terminals such as PowerShell, bash and zsh.
